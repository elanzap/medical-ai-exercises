# Solutions

Every exercise has a worked solution. Each solution notebook sits next to its exercise notebook with the suffix `-solution.ipynb`, and the course website links to it from the lesson.

The solutions are written in `solutions-src/<track>/` and generated into notebooks together with the exercises. Synthetic data that an exercise needs is in `exercise-data/<track>/` and appears in both notebooks.

Try the exercise first: the steps are designed to be worked through in order, using the worked example at the top of each notebook. The written answers in the solutions show one reasonable answer, not the only one.
